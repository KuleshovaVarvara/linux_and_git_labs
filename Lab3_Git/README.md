# Лабораторная работа №3. Основы Git

## Задание 1. Основные команды git

**Условие:**
1. Создайте новый git репозиторий в пустой директории.
2. Внутри директории создайте файл `text.txt` и выполните коммит данного файла в репозиторий.
3. Измените файл и выполните коммит внесённых изменений в репозиторий.
4. Выполните откат изменений и вернитесь к предыдущему коммиту. Просмотрите файл и убедитесь, что перед вами его предыдущая версия.
5. Сравните две версии файла и изучите вашу историю коммитов.

<details>
<summary><b>Показать решение</b></summary>

### 1) Создание репозитория

```bash
cd ~/Desktop
mkdir git_test
cd git_test
git init
```

### 2) Создание файла и первый коммит

```bash
echo "First text" > text.txt
git add text.txt
git commit -m "Updated text.txt"
```

### 3) Изменение файла и второй коммит

```bash
echo "Second text" >> text.txt
git add text.txt
git commit -m "Изменен файл text.txt"
```

### 4) Откат к предыдущему коммиту

Смотрим историю коммитов, чтобы узнать хеш первого коммита:

```bash
git log
```

Откатываемся к нему:

```bash
git reset --hard <hash_первого_коммита>
```

Проверяем содержимое файла — должна остаться только первая версия:

```bash
cat text.txt
```

### 5) Сравнение версий и история коммитов

```bash
git log
git show <hash_второго_коммита>
```

Для сравнения двух версий файла можно использовать:

```bash
git diff <hash_первого> <hash_второго> -- text.txt
```

## Задание 2. Базовые навыки работы с ветками git

**Условие:**
1. Разделите ваш репозиторий на две ветки.
2. Измените текущую ветку.
3. Измените файл и выполните коммит на каждой из веток.
4. Выполните слияние двух веток.
5. Выполните уровни из раздела основы руководства по git на сайте [learngitbranching.js.org](https://learngitbranching.js.org/?locale=ru_RU).

<details>
<summary><b>Показать решение</b></summary>

### 1) Создание второй ветки

```bash
git branch branch_2
```

### 2) Переключение на новую ветку

```bash
git checkout branch_2
```

### 3) Коммиты в каждой из веток

**Коммит в `branch_2`:**

```bash
echo "Text in branch_2" >> text.txt
git add text.txt
git commit -m "Change в branch_2"
```

**Коммит в `master` (или `main`):**

```bash
git checkout master
echo "Text in master" >> text.txt
git add text.txt
git commit -m "Change в master"
```

### 4) Слияние веток

```bash
git merge branch_2
```

Если возник конфликт, нужно вручную отредактировать файл, удалив маркеры конфликта:

```bash
nano text.txt
# удалить строки: <<<<<<<, =======, >>>>>>>
# оставить нужный текст
# Ctrl+O, Enter, Ctrl+X
```

Затем зафиксировать результат:

```bash
git add text.txt
git commit -m "Branch merging"
```
